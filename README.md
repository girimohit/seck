# SECK

Seck is a Windows desktop security application built using WPF and .NET.  
It provides real-time monitoring and control over running applications with a sleek cyber-themed user interface.

The project is designed to help users improve focus, security, and system control by monitoring active applications and enabling app-locking functionality.

---

## ✨ Features

- Real-time running application monitoring
- App locking and restriction system
- Live process detection
- Active app status indicators

---

## 🛠️ Tech Stack

- **C#**
- **WPF (.NET)**
- **XAML**
- **Windows Desktop APIs**
- **MVVM Architecture**

---

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Visual Studio 2022
- .NET SDK
- Windows Desktop Development workload

---

### Installation

Clone the repository:

```bash
git clone https://github.com/girimohit/seck.git
```

Open the project in Visual Studio and run:

```bash
dotnet run
```
